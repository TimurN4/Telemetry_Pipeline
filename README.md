# Telemetry Pipeline — gRPC Bidirectional Streaming Demo

Построение конвейера телеметрии на **gRPC C++** с использованием **Callback API** и **Bidirectional Streaming**.

Проект состоит из трёх узлов, связанных последовательно:

```
┌──────────┐   AccelPacket    ┌──────────────┐   AccelPacket    ┌──────────┐
│  Node_A  │ ───────────────► │    server    │ ───────────────► │  Node_B  │
│ (client) │                  │   (proxy)    │                  │ (server) │
│          │ ◄─────────────── │              │ ◄─────────────── │          │
└──────────┘  AccelModule     └──────────────┘   AccelModule    └──────────┘
   :57780                        :57780 / :57781                  :57781
```

- **Node_A** — клиент, который раз в секунду отправляет случайные пакеты ускорения (`AccelPacket`) и печатает приходящие обратно результаты (`AccelModule`).
- **server (Proxy)** — промежуточный узел. Принимает поток от Node_A, пересылает его в Node_B и возвращает ответы обратно в Node_A.
- **Node_B** — вычислительный узел. Принимает `AccelPacket`, вычисляет модуль вектора ускорения и отправляет `AccelModule` обратно.
